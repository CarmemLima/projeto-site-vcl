Projeto Vitrine CL Fitness.
Este é o meu primeiro projeto pessoal em desenvolvimento web.

O projeto é um site e-commerce desenvolvido para uma necessidade pessoal enquanto fui empreendedora de moda fitness e criadora da marca Vitrine CL Fitness.

O site é uma aplicação simples, desenvolvido com o objetivo de aprimoramento prático dos conhecimentos adquiridos sobre a base da programação, HTML5 e CSS3, aplicados a uma necessidade real e pessoal.

A hospedagem da aplicação foi na plataforma Netlify, onde pude explorar o processo básico de deploy do início ao fim.
